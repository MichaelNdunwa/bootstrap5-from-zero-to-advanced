# Bootstrap 5 – From Zero to Advanced 🚀

This repository is my **learning playground** for practicing Bootstrap 5 by following a set of **16 YouTube tutorials**.
Each tutorial is built in its own **branch** so I can track progress, experiment, and showcase different projects.

---

## 📚 Learning Goal

* Practice **Bootstrap 5 basics → advanced** through structured tutorials.
* Gain hands-on experience with **responsive layouts**, **components**, and **custom theming**.
* Build a portfolio of **mini landing pages & UI projects**.

---

## 📂 Repository Structure

The repository uses separate branches for each tutorial project:

* **[`aurora-tours`](https://github.com/MichaelNdunwa/bootstrap5-from-zero-to-advanced/tree/aurora-tours)**
  *A travel landing page project* (practiced from YouTube tutorial by **ByteGrad**).

* **[`techgears`](https://github.com/MichaelNdunwa/bootstrap5-from-zero-to-advanced/tree/techgears)**
  *A modern e-commerce gadgets landing page* (practiced from YouTube tutorial by **Coding with Sharan**).

👉 More branches will be added as I progress through the remaining tutorials.

---

## ▶️ How to Run Any Project

1. Clone the repository:

   ```bash
   git clone https://github.com/MichaelNdunwa/bootstrap5-from-zero-to-advanced.git
   ```
2. Switch to the desired branch:

   ```bash
   git checkout branch-name
   ```

   Example:

   ```bash
   git checkout aurora-tours
   ```
3. Open the `index.html` file in your browser.
